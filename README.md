# nfl-receipts

Frozen NFL predictions, committed before kickoff. Git history is the public record of when each prediction was published. Commits on `main` are never rewritten.

| Folder | Contents |
|---|---|
| `predictions/` | Official predictions, one file per game per publish point (OPEN, FRIDAY, FINAL). FINAL is the graded one. |
| `shadow/` | Test-week predictions. Not graded in the public record. |

The file format follows the output contract (coming soon).
